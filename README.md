## ⬇️ 下载

**[点这里下载最新版](https://github.com/SirChomuske/Claude-Niang/releases/latest)**，下载 `Claude-Niang-v1.0.0.zip`。

## ✨ 能做什么

- **点她说话**：内置 45 句本小姐语录。点角色打开一句，点气泡换下一句。
- **按一下会“噗叽”**：点击有挤压动画和吱吱音效，也能换成自己的 WAV 音效。
- **两套形象**：设置菜单 →「更换形象」，还能导入你自己的图片。建议使用透明图片。
- **回答结束提醒**：Claude Code 回答完毕时，她会告诉你「Claude 回答完毕啦」。
- **自由摆放**：拖动、缩放、置顶，或者只待在 Claude 桌面应用窗口里。
- **额度显示**：使用终端版 Claude Code 时，点她可以看 5 小时 / 每周剩余额度。

## 📋 需要什么

- Windows 10 / 11
- [Node.js](https://nodejs.org/) 20 或更新版本
- Claude 桌面应用或终端版 Claude Code

## 🚀 安装

1. 把 zip **解压到一个固定的位置**（例如 `D:\Apps\Claude-Niang`）。装好后不要移动或删除这个文件夹。
2. 打开 `claude-niang` 文件夹，双击 **`安装Claude娘.cmd`**。
   - 如果 Windows 提示“已保护你的电脑”，点「更多信息」→「仍要运行」。
3. 新开一个 Claude Code 会话，她就会出现在桌面上啦。

想要回答结束提醒的话，右键她（或点设置按钮）→ 开启「回答结束提醒」。

## ❓ 为什么桌面应用里看不到额度？

额度来自 Claude Code 的状态栏数据，而只有**终端版** Claude Code 会提供它。只用桌面应用时，Claude娘就是一个纯粹的桌面宠物，点击显示语录。

## 🗑️ 卸载

双击 `claude-niang\停用Claude娘.cmd`。她会离开桌面，你的 Claude Code 设置也会恢复原样。

## 🔒 隐私

不联网，不读取登录信息，不保存你的对话内容。只在本机记录额度数字和“回答结束”的时间。

# Claude-Chan (English)

An orange-haired girl holding a book who lives on your desktop and keeps you company while you code.

> Unofficial fan project. Not affiliated with or endorsed by Anthropic. "Claude" and "Clawd" are trademarks of Anthropic.

## ⬇️ Download

**[Download the latest release](https://github.com/SirChomuske/Claude-Niang/releases/latest)** and get `Claude-Niang-v1.0.0.zip`.

## ✨ Features

- **Quotes:** 45 built-in lines. Click her to open one; click the speech bubble for another. You can edit or add your own.
- **Squish!** Clicking her plays a squish animation and a squeaky-toy sound. You can swap in your own WAV sounds.
- **Two looks:** Settings menu → Change look. You can also import your own image. transparent background recommended.
- **Reply-finished reminder:** when Claude Code finishes a reply, she tells you so.
- **Put her anywhere:** drag, resize, keep on top, or keep her inside the Claude desktop app window.
- **Usage display:** if you use Claude Code in the terminal, click her to see your 5-hour and weekly usage left.

## 📋 Requirements

- Windows 10 / 11
- [Node.js](https://nodejs.org/) 20 or newer
- The Claude desktop app or Claude Code in the terminal

## 🚀 Install

1. **Extract the zip to a permanent folder**, e.g. `D:\Apps\Claude-Niang`. Don't move or delete it after installing.
2. Open the `claude-niang` folder and double-click **`安装Claude娘.cmd`** (Install).
   - If Windows says "Windows protected your PC", click **More info → Run anyway**.
3. Open a new Claude Code session and she'll appear on your desktop.

To turn on the reply-finished reminder: right-click her (or use the settings button) → 「回答结束提醒」.

## ❓ Why no usage display in the desktop app?

Usage comes from Claude Code's status line data, which only **terminal** Claude Code provides. If you only use the desktop app, Claude-Niang is simply a desktop pet and clicks show quotes.

## 🗑️ Uninstall

Double-click `claude-niang\停用Claude娘.cmd` (Disable). She leaves your desktop and your Claude Code settings are restored.

## 🔒 Privacy

Nothing goes online. She doesn't read your login or store your conversations. Only usage numbers and "reply finished" times are saved, on your own PC.
